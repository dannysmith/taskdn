# Getting Started

Welcome to your Taskdn vault! This is a starter template for managing tasks, projects, and areas using markdown files.

## Quick Links

- [[tasks/Overview|Tasks Overview]] - See all your tasks
- [[projects/Overview|Projects Overview]] - See all your projects
- [[areas/Overview|Areas Overview]] - See all your areas

## How It Works

**Tasks** are actionable items stored in `tasks/`. Each task has a status (inbox, ready, in-progress, blocked, done, etc.) and can belong to a project or area.

**Projects** are collections of tasks with a defined goal. They live in `projects/` and can belong to an area.

**Areas** are ongoing areas of responsibility (like "Work" or "Health"). They live in `areas/` and help organize projects and tasks by life domain.

## Creating New Items

Use Obsidian's Templates plugin:

1. Create a new file in the appropriate folder
2. Run **Insert template** (Cmd/Ctrl + P → "Insert template")
3. Choose Task, Project, Area, or Trip Project template
4. Fill in the frontmatter fields

## The Plugin

If you have the **obsidian-taskdn** plugin installed, wikilinks to tasks render as interactive widgets. See [[example-note]] for a demonstration.
