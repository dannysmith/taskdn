## The Idea

Build a custom mechanical keyboard as a fun project. Interested in the process and would end up with something unique.

## Still Deciding

- **Form factor:** 65% vs 75% vs TKL
- **Switches:** Tactile (thinking Boba U4T) vs Linear (Gateron Yellows?)
- **Keycaps:** GMK vs cheaper PBT alternatives
- **PCB/Case:** GMMK Pro, Keychron Q series, or full custom
