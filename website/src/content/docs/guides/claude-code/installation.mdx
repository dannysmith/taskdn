<Aside type="note">
You need the [Taskdn CLI](/guides/cli/installation) installed and configured first.
</Aside>

## From Marketplace

<Steps>
1. Open Claude Code

2. Run the install command:
   ```
   /plugin install tdn@tdn-marketplace
   ```

3. Verify the plugin is loaded:
   ```
   /plugin list
   ```
</Steps>

## Local Development

Load the plugin directly from a local path:

```bash
claude --plugin-dir /path/to/tdn-claude-plugin
```

## Configuration

The plugin uses your existing CLI configuration. Ensure you have a valid `~/.taskdn.json` pointing to your vault.
