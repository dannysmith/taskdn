## Available Commands

### /tdn:today

Show today's actionable tasks:

```
/tdn:today
```

Equivalent to running `tdn today --ai` and displays tasks that are in-progress, overdue, due today, scheduled today, or newly actionable.

## Natural Language

Beyond slash commands, just ask Claude naturally:

- "What tasks are due this week?"
- "Add a task to review the PR"
- "What's the status of the Q1 project?"
- "Archive all the done tasks"

Claude will use the appropriate `tdn` commands.
