## Overview

With the plugin installed, you can ask Claude:

- "What should I focus on today?"
- "Create a task to call the dentist"
- "Show me the Q1 Planning project status"
- "Mark the report task as done"
- "What's overdue?"

Claude uses the `tdn` CLI with `--ai` mode to query and modify your tasks.
