## Files on Disk

Taskdn stores everything as markdown files with YAML frontmatter. Your data is yours — portable, readable, and works with any tool that understands markdown.

## Opinionated About Tasks

We have strong opinions about how tasks should work, but none about how you organise your notes, projects, or areas.

## Multiple Interfaces

The same files work with the CLI, desktop app, and Obsidian plugin. Choose the right tool for your context.
