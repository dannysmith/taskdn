## Files on Disk

Taskdn stores everything as markdown files with YAML frontmatter. Your data is yours — portable, readable, and works with any tool that understands markdown.

## Opinionated About Tasks

We have strong opinions about how tasks should work, but none about how you organise your notes, projects, or areas.

## Multiple Interfaces

The same files work with the CLI, desktop app, and Obsidian plugin. Choose the right tool for your context.

### 6.1 Design Rationale

**Why one file per task?**
Individual files allow tasks to be edited with any text editor, processed by command-line tools, and managed by AI coding assistants more easily than . They also enable rich note-taking within each task.

**Why require a `tasks` directory?**
A dedicated directory simplifies discovery and prevents implementations from scanning entire file systems. It also clearly separates actionable items from other content.

**Why YAML frontmatter?**
YAML frontmatter is widely supported by note-taking apps (Obsidian, Logseq), and developer tools. It balances human readability with machine parseability.

**Why these specific status values?**
The status values are designed to support common task management workflows (GTD-inspired inbox processing, blocking dependencies, intentional deferral) while remaining simple enough for quick triage.
