## Install

<Tabs syncKey="pkg">
  <TabItem label="Homebrew" icon="apple">
    ```bash
    brew install dannysmith/taproom/tdn
    ```
  </TabItem>
  <TabItem label="Binary">
    Download from [GitHub Releases](https://github.com/dannysmith/taskdn/releases) and add to your PATH.
  </TabItem>
</Tabs>

Verify the installation:

```bash
tdn --version
```

## Configuration

Taskdn looks for configuration in these locations (highest priority first):

1. Environment variables (`TASKDN_TASKS_DIR`, etc.)
2. Local config (`./.taskdn.json`)
3. User config (`~/.taskdn.json`)
4. Defaults (`./tasks`, `./projects`, `./areas`)

### Config File

```json title=".taskdn.json"
{
  "tasksDir": "~/notes/tasks",
  "projectsDir": "~/notes/projects",
  "areasDir": "~/notes/areas",
  "ignore": ["*.bak", "README.md"]
}
```

### Interactive Setup

Run `tdn init` to create a config file interactively.

### Health Check

Run `tdn doctor` to verify your vault is configured correctly.
