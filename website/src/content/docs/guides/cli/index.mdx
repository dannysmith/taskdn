## Overview

The CLI provides different output modes for different users:

- **Human mode** (default) — Pretty terminal output with colors and interactive prompts
- **AI mode** (`--ai`) — Structured markdown optimised for LLM consumption
- **JSON mode** (`--json`) — Machine-readable structured data
