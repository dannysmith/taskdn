## List Tasks

```bash
tdn list                           # All active tasks
tdn list --status ready            # Ready tasks only
tdn list --due today               # Due today
tdn list --project "Q1 Planning"   # Tasks in a project
```

### Filtering

Multiple filters combine with AND logic. Multiple values for the same filter use OR logic.

```bash
tdn list --status ready,in-progress --due this-week
```

### Sorting

```bash
tdn list --sort due              # Sort by due date
tdn list --sort due --desc       # Newest first
```

## Show Task Details

```bash
tdn show "Fix login bug"
```

Shows full frontmatter and body content.

## Today's Tasks

```bash
tdn today
```

Shows tasks that need attention today: in-progress, overdue, due today, scheduled today, and newly actionable.
