## The Context Command

The `context` command returns hierarchical information about your work — perfect for priming AI assistants.

```bash
tdn context --ai                    # Vault overview
tdn context area "Work" --ai        # Area with projects and tasks
tdn context project "Q1" --ai       # Project with tasks
tdn context task "Fix bug" --ai     # Task with parent context
```

## AI Mode

The `--ai` flag produces structured markdown optimised for LLM consumption:

- **Token-efficient** — Compact notation, emoji status indicators
- **Progressive disclosure** — Most important info first
- **Gracefully degradable** — Truncated output remains useful
- **File paths included** — For follow-up commands

## Example Output

```markdown
# Overview

**Stats:** 3 areas · 8 projects · 34 tasks · ▶️ 5 in-progress

## Structure

### 📁 Work
├── 🔵 Q1 Planning [in-progress] — 8 tasks (2▶️ 4🟢 1📥)
│   ├── ▶️ Fix authentication bug
│   └── ▶️ Document API v2
```

## Using with AI Assistants

AI agents should:
1. Call `tdn context --ai` first to understand the vault
2. Use file paths from the output for follow-up commands
3. Use `--ai` mode for all queries to avoid interactive prompts
