## The Problem

You want your notes, projects, and tasks in one place as plain files you own. Tools like Obsidian are great for documents, but **terrible for task management**. The ideal UI for tasks is completely different to that for documents.

## The Solution

Taskdn gives you the best of both worlds: **tasks as markdown on disk**, with purpose-built tools that work brilliantly in each context.

## How It Works

Tasks, projects, and areas are markdown files with structured frontmatter:

```yaml
---
title: Review quarterly report
status: in-progress
due: 2025-01-15
projects:
  - "[[Q1 Planning]]"
---

Notes, context, whatever you want in the body...
```

That's it. No database, no sync service, no magic. Just files.
