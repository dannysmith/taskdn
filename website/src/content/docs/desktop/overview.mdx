## Features

- **Quick capture** — Global keyboard shortcut to add tasks from anywhere. Type naturally, mention projects with `/`, add dates with `@`.
- **Smart views** — Inbox, Today, This Week, Overdue. See what matters without configuring anything.
- **Multiple layouts** — List view for focused work, Kanban boards for visual planning, weekly calendar for scheduling. Each view uses whatever layout fits.
- **Task detail sidebar** — Select a task to edit all its fields: status, dates, project, area, and any notes in the body.
- **Keyboard-first** — Navigate views, select tasks, edit properties, create new items. Everything works without touching the mouse.
- **Command palette** — Quick access to any action, with contextual commands for the currently selected item.
- **Search** — Fuzzy search across all tasks, projects, and areas. Find anything in a few keystrokes.
- **URL scheme** — Deep links to open specific tasks, projects, or views from other apps or scripts.

## What This Isn't

This is a task app, not a file browser or project management system. You won't find a way to edit area files or write long project documents here. For that, use Obsidian or any text editor—the files are right there on disk. The desktop app is focused on one thing: helping you manage and complete your tasks.
