## Getting Started

Taskdn is a monorepo containing multiple products:

| Directory | Product | Stack |
|-----------|---------|-------|
| `tdn-cli/` | CLI | TypeScript/Bun + Rust |
| `tdn-desktop/` | Desktop App | Tauri + React |
| `tdn-claude-plugin/` | Claude Code Plugin | Markdown |
| `website/` | Documentation | Astro/Starlight |

The Obsidian plugin lives in a separate repo: [dannysmith/obsidian-taskdn](https://github.com/dannysmith/obsidian-taskdn)

## Development Setup

```bash
git clone https://github.com/dannysmith/taskdn
cd taskdn
```

Each product has its own setup. See the README in each directory.

## Submitting Changes

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests and linting
5. Submit a pull request

## Code Style

- TypeScript: Prettier + ESLint
- Rust: `cargo fmt` + Clippy

## Questions?

Open an issue on GitHub.
