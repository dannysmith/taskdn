## Current Focus

The desktop app. Once that's in a usable state, the focus shifts to refinement across all the products.

## Future Plans

- **Rust SDK** for working with task files programmatically
- **TypeScript SDK** for the same
- **Raycast plugin** for quick capture and task lookup
- **More Claude Code features**: additional slash commands, expanded skill capabilities, better review workflows

The Obsidian plugin is largely complete. No major features planned there.
