Initial release of the Taskdn plugin for Claude Code.

## Features

- **Task management skill** - Helps Claude work as a productivity assistant, managing tasks, projects, and areas stored as markdown files
- **`/tdn:today` command** - Get tasks that matter right now (in-progress, overdue, due today, scheduled today)
- **`/tdn:prime` command** - Prime a session with general context from your task system

The plugin integrates with the `tdn` CLI to provide task and project management directly within Claude Code sessions.
