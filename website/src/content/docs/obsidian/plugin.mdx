The Obsidian plugin turns wikilinks to task files into interactive widgets. Link to a task from anywhere in your vault and see its status, project, dates, and other metadata inline. Check off tasks without opening the file.


## Features

- **Interactive task widgets** — Wikilinks to tasks render with checkboxes, status indicators, project/area, and due dates
- **Status colours** — Coloured borders show task state at a glance (blue for inbox, yellow for in-progress, red for blocked)
- **Check off tasks** — Click the checkbox to mark tasks done without leaving your note
- **Convert checklist items** — Right-click any checklist item to turn it into a Taskdn task file
- **Inline title replacement** — Display the task's title frontmatter instead of the kebab-case filename, with a status-coloured border

## Installation

The plugin needs Obsidian 1.13 or later, with **Use `[[Wikilinks]]`** turned on in **Settings → Files and links**.

### From Community Plugins

Taskdn is in Obsidian's [community plugin directory](https://community.obsidian.md/plugins/taskdn). If you have Obsidian installed, this button opens Taskdn's page in Obsidian's plugin browser. Click **Install**, then **Enable**.

<LinkButton href="obsidian://show-plugin?id=taskdn" icon="external">Add to Obsidian</LinkButton>

Or find it from inside Obsidian:

<Steps>

1. Go to **Settings → Community plugins** and turn on community plugins if you haven't already

2. Click **Browse** and search for "Taskdn"

3. Click **Install**, then **Enable**

</Steps>

Obsidian keeps the plugin up to date along with your other community plugins.

### Manual Install

<Steps>

1. Download `main.js`, `manifest.json` and `styles.css` from the [latest release](https://github.com/dannysmith/obsidian-taskdn/releases/latest)

2. Copy them into `YOUR_VAULT/.obsidian/plugins/taskdn/`, creating the `taskdn` folder if it doesn't exist

   The `.obsidian` folder is hidden by default. Press `Cmd+Shift+.` in the macOS Finder or `Ctrl+H` in most Linux file managers to show it.

3. Restart Obsidian

4. Go to **Settings → Community plugins**, find "Taskdn", and enable it

</Steps>

:::tip[Installed it by hand before?]
Earlier versions of these instructions used `.obsidian/plugins/obsidian-taskdn/` as the folder. Close Obsidian and rename that folder to `taskdn`. Your settings come with it, and Obsidian updates the plugin like any other community plugin from then on.
:::

## Configuration

Open **Settings → Taskdn** to configure the plugin. Changes apply straight away, and the settings show up in Obsidian's settings search.

| Setting | Description |
|---------|-------------|
| Tasks directory | Folder containing your task files (default: `tasks`) |
| Default status for new tasks | Status given to tasks converted from checklist items: `inbox`, `ready` or `icebox` (default: `inbox`) |
| Show desktop app button | Adds a button to task widgets that opens the task in the [desktop app](/desktop/overview) (default: off) |
| Ignored files | Task files that never render as widgets, one pattern per line. Paths are relative to the tasks directory and `*` is a wildcard, for example `archive/*` or `*-template` |
| Use task title as inline title | Show the `title` frontmatter instead of the filename in the inline title. Only appears when Obsidian's **Show inline title** is on |
| Sync filename with task title | Also rename the file when you edit the inline title. Only appears when **Use task title as inline title** is on |

## Usage

<Image src={obsidianScreenshot} alt="Taskdn tasks rendered as interactive widgets in Obsidian" />


Link to task files using standard wikilink syntax:

```md
- [[call-dentist]]
- [[review-quarterly-report]]
- Check out [[website-redesign]] when you have time
```

Works in both Live Preview and Reading mode. Tasks in bullet lists behave like native Obsidian checklists—completed tasks get strikethrough styling.

## Inline Title

By default, Obsidian displays the filename as the inline title at the top of documents. For task files, this means you see `buy-groceries` instead of "Buy groceries". The plugin can replace this with the human-readable title from frontmatter.

### Setup

1. Enable **Settings → Appearance → Show inline title** (Obsidian's native setting)
2. Enable **Settings → Taskdn → Use task title as inline title**

### Status Border

When enabled, a coloured left border appears indicating the task's status:

| Status | Border Colour |
|--------|---------------|
| inbox | Blue |
| icebox | Cyan |
| ready | Grey |
| in-progress | Yellow |
| blocked | Red |
| dropped | Pink |
| done | Green |

### Editing the Title

Click the inline title to edit. When you finish (press Enter or click away), the plugin:

1. Updates the `title` frontmatter
2. Sets `updated-at` to today's date
3. Optionally renames the file (if "Sync filename with task title" is enabled)

Press Escape to cancel without saving.

The standard Obsidian behaviour of renaming the file is intercepted—your edits go to the frontmatter instead.

### Filename Sync

Enable **Sync filename with task title** to rename files when editing the inline title:

- Filenames are converted to kebab-case ("Buy Groceries" → `buy-groceries.md`)
- Obsidian updates all wikilinks automatically
- Duplicate names get a number suffix (`buy-groceries-2.md`)

### When It Applies

The inline title replacement only activates when all of these conditions are met:

1. The file is in your configured tasks directory
2. The file isn't matched by any pattern in **Ignored files**
3. The file has valid frontmatter with both `title` and `status` fields

For all other files, Obsidian's normal inline title behaviour applies—edits will rename the file as usual.
