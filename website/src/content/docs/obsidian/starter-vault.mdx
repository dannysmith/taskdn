The starter vault is a ready-made Obsidian vault with templates, [Bases](https://obsidian.md/help/bases) views and example content. Clone it to start managing your tasks in Obsidian, or just to try Taskdn out. It needs Obsidian 1.14 or later.

## Installation

<Steps>

1. Clone the starter vault:

   ```bash
   git clone https://github.com/dannysmith/tdn-obsidian-starter-vault my-tasks
   cd my-tasks
   ./shift-dates.sh
   rm -rf .git README.md shift-dates.sh
   ```

   `./shift-dates.sh` is optional. It moves the dates in the example content so they're relative to today, which gives the Today and Upcoming views something to show. Skip it and the examples just look old.

2. In Obsidian, click **Open folder as vault** and choose the cloned folder. The vault opens on `Start Here.md`.

</Steps>

Bases, Templates and wikilinks are already turned on, and the date fields are set up as date properties, so there's nothing else to configure. For task widgets in your notes, add the [Taskdn plugin](#taskdn-plugin).

## Start Here

`Start Here.md` is a dashboard built from the vault's bases:

- **Today**: in-progress tasks, anything due or scheduled today or earlier, and tasks that became available today
- **Board**: your tasks as a kanban board. Drag a card to another column to change its status.
- **Active Projects**: projects that are planning, ready or in progress
- **Tasks in Your Notes**: task links mixed with plain checkboxes, which render as live tasks with the [Taskdn plugin](/obsidian/plugin)

Edit it into your own dashboard, or pick a different note to open in **Settings → Files and links → Default file to open**.

## Templates

Create new tasks, projects, and areas with Obsidian's Templates plugin, which is already pointed at the `templates/` folder. Each template includes the required frontmatter fields.

**Task Template**: `ready` status, today's date for `created-at` and `updated-at`, and empty fields for `due`, `scheduled`, `defer-until`, `projects`, and `area`.

**Project Template**: `planning` status, today's date for `start-date`, and sections for an overview, the project's tasks and next steps.

**Area Template**: `active` status, a prompt to define what "doing well" looks like, and the area's projects and tasks.

**Trip Project Template**: an example of a project-specific template, with sections for itinerary, transport and accommodation, a planning checklist and a kit list.

To use a template, create a new file in the appropriate directory, then run the **Insert template** command (`Cmd/Ctrl + P` → "Insert template").

## Bases

[Obsidian Bases](https://obsidian.md/help/bases) let you create database-like views of your notes. Every view in the starter vault comes from the three bases in `templates/bases/`. Open one to see all its views, or edit them to suit how you work.

### Included Bases

**Tasks.base**

- **Board**: kanban by status, leaving out archived tasks and tasks deferred until later
- **Today**: in-progress tasks, anything due or scheduled today or earlier, and tasks that became available today
- **Upcoming**: tasks due, scheduled or becoming available in the next 14 days
- **Active**: everything not done, dropped, in the icebox or deferred, grouped by status
- **All**: every task, most recently updated first
- **Linked Tasks**: embedded in project and area notes to list the tasks that link to them

**Projects.base**

- **Board**: kanban by status
- **Active**: projects that are planning, ready or in progress
- **All Projects**
- **Linked Projects**: embedded in area notes to list the projects that link to them

**Areas.base**

- **Active**: every area that isn't archived
- **All Areas**

### Overview Pages

`tasks/`, `projects/` and `areas/` each have an `Overview.md` that embeds that folder's base. Switch between its views using the tabs.

Embed a base view in any note using:

```md
![[Tasks.base]]
![[Tasks.base#Today]]
```

## Taskdn Plugin

The [Taskdn plugin](/obsidian/plugin) is optional. It renders wikilinks to tasks as interactive widgets: open `example-note.md` or the "Tasks in Your Notes" section of `Start Here.md` to see it in action.

<Steps>

1. With the vault open in Obsidian, click this button to open Taskdn's page in Obsidian's plugin browser, then click **Install** and **Enable**:

   <LinkButton href="obsidian://show-plugin?id=taskdn" icon="external">Add to Obsidian</LinkButton>

   If the button doesn't open Obsidian, go to **Settings → Community plugins**, turn on community plugins, click **Browse** and search for "Taskdn".

2. In **Settings → Taskdn**, set **Ignored files** to `Overview.md`

</Steps>

The default tasks directory, `tasks`, already matches the vault. Ignoring `Overview.md` stops links to the tasks Overview rendering as a task widget.

### Folder Notes (Optional)

If you use the [Folder Notes](https://github.com/LostPaul/obsidian-folder-notes) plugin, set its **Folder note name** to `Overview` and restart Obsidian. Clicking `tasks/`, `projects/` or `areas/` in the file explorer then opens that folder's Overview, and the Overview files are hidden from the file list.

## Web Clipper Template

If you use the [Obsidian Web Clipper](https://obsidian.md/clipper), you can create a template that saves web pages directly as inbox tasks. The clipped content goes in the task body, ready for processing later.

To add the template, open the Web Clipper settings and import this JSON:

```json
{
  "schemaVersion": "0.1.0",
  "name": "Taskdn Task",
  "behavior": "create",
  "noteContentFormat": "Clipped from: {{url}}\n\n{{content}}",
  "properties": [
    {
      "name": "title",
      "value": "{{title}}",
      "type": "text"
    },
    {
      "name": "status",
      "value": "inbox",
      "type": "text"
    },
    {
      "name": "created-at",
      "value": "{{date}}",
      "type": "date"
    },
    {
      "name": "updated-at",
      "value": "{{date}}",
      "type": "date"
    }
  ],
  "triggers": [],
  "noteNameFormat": "{{title|safe_name}}",
  "path": "tasks"
}
```

See the [CLI documentation](/cli/overview) for other ways to capture tasks, including from the command line and via AI assistants.
