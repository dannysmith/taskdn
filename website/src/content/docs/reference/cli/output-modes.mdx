## Mode Selection

| Flags | Mode | Use Case |
|-------|------|----------|
| (none) | Human | Terminal display |
| `--ai` | AI | LLM consumption |
| `--json` | JSON | Programmatic access |
| `--ai --json` | AI-JSON | AI with JSON envelope |

## Human Mode

- Colored, formatted terminal output
- Interactive prompts when needed
- Friendly error messages

## AI Mode

Structured Markdown optimised for LLMs:

- Token-efficient compact notation
- File paths always included
- No interactive prompts
- Gracefully degradable when truncated

### Why Markdown?

1. More compact than JSON
2. Truncated output remains useful
3. LLMs read it directly without parsing
4. LLMs are trained on Markdown

## JSON Mode

Machine-readable structured data:

- All fields in camelCase
- Includes `summary` field
- Structured error objects

### Field Name Mapping

| AI/File | JSON |
|---------|------|
| `created-at` | `createdAt` |
| `defer-until` | `deferUntil` |
| `completed-at` | `completedAt` |

## AI-JSON Mode

AI Markdown wrapped in JSON envelope:

```json
{
  "contextType": "overview",
  "entity": null,
  "summary": "Overview of all active work",
  "content": "# Overview\n\n**Stats:**...",
  "references": [
    { "name": "Work", "type": "area", "path": "areas/work.md" }
  ]
}
```
