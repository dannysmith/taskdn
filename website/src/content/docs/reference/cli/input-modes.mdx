## Human Mode (Interactive)

Default behavior when running in a terminal:

- **Fuzzy matching:** Partial titles resolve to full matches
- **Disambiguation prompts:** Multiple matches show selection menu
- **Confirmations:** Destructive operations may prompt
- **Interactive creation:** `tdn new` with no args prompts for fields

### Ctrl-C Handling

Ctrl-C always cancels safely with no partial operations.

## AI Mode (Non-Interactive)

When `--ai` or `--json` is set:

- **No prompts:** Commands succeed or fail with structured error
- **Exact paths preferred:** Fuzzy matching works but paths are unambiguous
- **Batch-friendly:** Multiple items can be processed in one command

## Entity Lookup

### Path Detection

A query is treated as a file path if it:

- Starts with `/`, `./`, `../`, or `~`
- Contains path separators
- Ends with `.md`

### Fuzzy Matching

Non-path queries use case-insensitive substring matching:

- "login" matches "Fix login bug"
- Exact match accepted immediately
- Single match accepted automatically
- Multiple matches: prompt (human) or error (AI)

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Success (including empty results) |
| `1` | Runtime error (file/vault issues) |
| `2` | Usage error (invalid arguments) |
