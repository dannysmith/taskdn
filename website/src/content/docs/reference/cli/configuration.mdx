## Config File Locations

| Priority | Location | Scope |
|----------|----------|-------|
| 1 | Environment variables | Session |
| 2 | `./.taskdn.json` | Project |
| 3 | `~/.taskdn.json` | User |
| 4 | Defaults | Fallback |

## Config Schema

```json title=".taskdn.json"
{
  "tasksDir": "~/notes/tasks",
  "projectsDir": "~/notes/projects",
  "areasDir": "~/notes/areas",
  "ignore": ["*.bak", "*.tmp", "README.md"]
}
```

## Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `tasksDir` | string | `./tasks` | Path to tasks directory |
| `projectsDir` | string | `./projects` | Path to projects directory |
| `areasDir` | string | `./areas` | Path to areas directory |
| `ignore` | string[] | — | Filename patterns to exclude |

Paths support `~` for home directory.

## Environment Variables

| Variable | Config Field |
|----------|--------------|
| `TASKDN_TASKS_DIR` | `tasksDir` |
| `TASKDN_PROJECTS_DIR` | `projectsDir` |
| `TASKDN_AREAS_DIR` | `areasDir` |

## Ignore Patterns

Patterns use `.gitignore`-style glob syntax and match filenames only:

| Pattern | Matches |
|---------|---------|
| `file.md` | Exact filename |
| `*.bak` | Any `.bak` file |
| `temp?.md` | `temp1.md`, `tempA.md` |

**Case sensitivity:** macOS/Windows insensitive, Linux sensitive.

## Override Behavior

Local config replaces user config (no merging). If local has `ignore`, user's `ignore` is ignored.
