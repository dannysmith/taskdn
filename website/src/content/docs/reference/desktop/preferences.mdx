## Advanced

### settings.json

Preferences are stored in:

- **macOS:** `~/Library/Application Support/taskdn/settings.json`
- **Windows:** `%APPDATA%\taskdn\settings.json`
- **Linux:** `~/.config/taskdn/settings.json`
