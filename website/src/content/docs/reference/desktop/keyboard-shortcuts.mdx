## Global

| Shortcut | Action |
|----------|--------|
| `⌘ K` | Open command palette |
| `⌘ N` | New task (quick capture) |
| `⌘ /` | Quick search |
| `⌘ ,` | Preferences |

## Navigation

| Shortcut | Action |
|----------|--------|
| `⌘ 1` | Go to Today |
| `⌘ 2` | Go to Inbox |
| `⌘ 3` | Go to This Week |
| `↑ ↓` | Navigate items |
| `Enter` | Open selected item |
| `Escape` | Close / go back |

## Task Actions

| Shortcut | Action |
|----------|--------|
| `Space` | Toggle done |
| `⌘ E` | Edit task |
| `⌘ D` | Set due date |
| `⌘ S` | Set scheduled date |
| `⌘ ⌫` | Delete / drop task |
