## Overview

The desktop app registers the `taskdn://` URL scheme for deep linking.

## Supported URLs

| URL | Action |
|-----|--------|
| `taskdn://` | Open app |
| `taskdn://today` | Open Today view |
| `taskdn://inbox` | Open Inbox view |
| `taskdn://new` | Open quick capture |
| `taskdn://task/{path}` | Open specific task |
| `taskdn://project/{path}` | Open specific project |
| `taskdn://area/{path}` | Open specific area |

## Examples

```
taskdn://task/tasks/fix-login-bug.md
taskdn://project/projects/q1-planning.md
taskdn://new?title=Call%20dentist
```

## Query Parameters

For `taskdn://new`:

| Parameter | Description |
|-----------|-------------|
| `title` | Task title |
| `status` | Initial status |
| `due` | Due date |
| `project` | Project reference |
