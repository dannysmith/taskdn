# AI Agent Instructions for Taskdn Website

## Purpose

This is the public-facing website for Taskdn. It serves as:

1. **Marketing site** - Landing page, feature overview, getting started
2. **Documentation** - User guides for all Taskdn tools
3. **Specifications** - The formal Taskdn spec for implementers

## Stack

Built with [Astro](https://astro.build/) using the [Starlight](https://starlight.astro.build/) documentation theme and [Flexoki](https://stephango.com/flexoki) color theme.

## Directory Structure

```
website/
├── src/
│   ├── content/
│   │   └── docs/           # All content lives here as .md or .mdx
│   │       └── index.mdx   # Homepage (splash template)
│   └── content.config.ts   # Content collection config (rarely touched)
├── public/
│   ├── favicon.svg
│   └── robots.txt          # Includes sitemap reference
├── astro.config.mjs        # Site config, sidebar, social links, SEO
├── eslint.config.js
├── prettier.config.js
└── tsconfig.json
```

## Working with Content

- Add pages as `.md` or `.mdx` files in `src/content/docs/`
- File path = URL path (e.g., `docs/guides/cli.md` → `/guides/cli`)
- Every page needs frontmatter with at least `title` and `description`
- Sidebar is configured in `astro.config.mjs` - can be manual or autogenerated per directory

| Command                | Action                       |

| `bun dev`              | Start dev server (port 4321) |

| `bun run check`        | TypeScript checking          |

## SEO & Meta

Configured in `astro.config.mjs`:

- **Sitemap**: Auto-generated by Starlight (`/sitemap-index.xml`)
- **Open Graph**: Basic og:type, og:site_name, twitter:card set globally; Starlight auto-adds og:title, og:description, og:url per page
- **LLM context**: [starlight-llms-txt](https://delucis.github.io/starlight-llms-txt/) generates `/llms.txt`, `/llms-full.txt`, `/llms-small.txt`

To add dynamic OG images later, see [HiDeoo's guide](https://hideoo.dev/notes/starlight-og-images/) using `astro-og-canvas`.

## Quick Reference

Use `.mdx` (not `.md`) when you need components. Import at the top of the file:

```mdx
import { Aside, Steps, Tabs, TabItem } from '@astrojs/starlight/components'
```

### Asides

Callout boxes for tips, warnings, etc.

```mdx
<Aside>Default note aside.</Aside>
<Aside type="tip">Helpful suggestion.</Aside>
<Aside type="caution">Proceed carefully.</Aside>
<Aside type="danger">Critical warning.</Aside>
```

### Steps

Numbered instructions for tutorials/guides.

```mdx
<Steps>
1. First step with **markdown** support.
2. Second step.
</Steps>
```

### Tabs

Tabbed content (e.g., for different package managers). Use `syncKey` to keep tabs in sync across the page.

```mdx
<Tabs syncKey="pkg">
  <TabItem label="bun">bun install</TabItem>
  <TabItem label="npm">npm install</TabItem>
</Tabs>
```

### Cards

Feature cards and link cards for navigation.

```mdx
import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components'

<CardGrid>
  <Card title="Feature" icon="star">Description here.</Card>
  <LinkCard title="Guide" href="/guides/intro/" />
</CardGrid>
```

### FileTree

Visualise directory structures. Use `**bold**` to highlight, `...` for truncation.

```mdx
import { FileTree } from '@astrojs/starlight/components'

<FileTree>
- src/
  - content/
    - docs/
      - **index.mdx**
  - ...
- astro.config.mjs
</FileTree>
```

### Badge

Inline status labels.

```mdx
import { Badge } from '@astrojs/starlight/components'

<Badge text="New" variant="tip" />
<Badge text="Deprecated" variant="caution" />
```

Variants: `note` (default), `tip`, `caution`, `danger`, `success`

## Code Blocks (Expressive Code)

Starlight uses [Expressive Code](https://expressive-code.com/) for advanced code block rendering.

### Titles

Add a title to show a filename or description:

````md
```js title="config.js"
export default {}
```
````

### Terminal Frames

Shell languages (`bash`, `sh`, `zsh`) auto-render as terminals:

````md
```bash
npm install
```
````

Add a title for context:

````md
```bash title="Install dependencies"
npm install && npm run build
```
````

Disable the terminal frame with `frame="none"`:

````md
```bash frame="none"
echo "Plain code, no frame"
```
````

### Line Highlighting

Highlight specific lines with `{ }`:

````md
```js {2,4-5}
const a = 1
const b = 2  // highlighted
const c = 3
const d = 4  // highlighted
const e = 5  // highlighted
```
````

### Text Markers

Highlight specific text with quotes:

````md
```js "config"
const config = loadConfig()
```
````

### Insertions & Deletions

Show added/removed lines (diff style):

````md
```js ins={2} del={1}
const old = 'remove me'
const new = 'add me'
```
````

Or combine diff markers with syntax highlighting:

````md
```diff lang="js"
- console.log('old')
+ console.log('new')
```
````
