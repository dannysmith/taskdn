# Task: Keyboard Navigation & Shortcuts Improvement


## Phase 1: Task Commands

When a task is selected we should support similar keyboard shortcuts to Things. Cmd + N already works, as do Cmd Up/Down.

1. New to-dos from clipboard	(Cmd V)
  - A new to-do will be created for each separate row of text on your clipboard.
2. Duplicate Selected Item (Cmd Shift D)
3. Copy Selected Item Title (Cmd C)
4. Copy Absolute Path for Selected Item (Opt Cmd C)
5. Move item to top of list (Opt Cmd Up)
6. Move item to bottom of list (Opt Cmd Down)
7. Edit Scheduled Date (Cmd D) - Opens date editor dropdown
8. Set Scheduled Date to Today (Cmd T)
9. Edit Due Date (Shift Cmd D) - opens date editor
9. Edit Defer Until Date (Shift Opt Cmd D) - opens date editor
10. Edit Status (Cmd S) - Opens status changed dropdown

Thinks Keyboard Shortcuts (for information only): https://culturedcode.com/things/support/articles/2785159/
