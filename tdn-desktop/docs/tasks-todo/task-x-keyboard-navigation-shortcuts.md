# Task: Keyboard Navigation & Shortcuts

## Keyboard Navigation

Navigating around in the task list should feel easy and natural.

- It should be possible to command click and option click in task lists to select ranges of tasks.
- the keyboard commands to move task items up and down in task lists must work in task lists combine boards and basically in any other view where ordering is applicable Except the sidebar.
- It should be very easy to tab around different parts of the UI if necessary for keyboard navigability.
- Automatic focus states, Escape to cancel and tab order should be correct.

## Keyboard Shortcuts

- We should support common keyboard shortcuts as per Things 3 for various actions on tasks.
- We should be able to create new tasks, duplicate tasks in Sit Chu using keyboard shortcuts (same commands as right-click etc)
