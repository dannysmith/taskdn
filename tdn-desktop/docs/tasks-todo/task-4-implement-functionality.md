# Task: Implement Functionality & Tests

The goal of this task is to systematically work through all the functionality of the application and ensure that it is correctly wired up and working. As we work through each piece of functionality we should ensure that all of the relevant UI elements work, that reads work correctly from the actual tasks, that writes work correctly, and that the firewatcher correctly picks up changes and re renders the UI appropriately. As we're doing this, we should also be writing unit test for any particular business functionality, Rust test for any new functionality that we add to Rust, and end to end tests for testing the React stuff & UI.

The end goal is to essentially have a working app with good test coverage of the functionality Which exists in the UI so far.
